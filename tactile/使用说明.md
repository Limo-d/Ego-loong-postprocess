# 触觉手套工具包使用说明

本目录为**自包含**工具包：串口库、2D/3D 可视化、弯曲解耦、滑移检测，以及 MANO 模型、布局资源与辅助脚本均位于 `tactile/` 内。默认设备协议为 ASCII 行 `TOUCH seq=... thumb=... index=... middle=... ring=... little=... palm=...`，波特率 **921600**。

---

## 1. 目录结构

```text
tactile/
├── 使用说明.md                 # 本文件
├── tactile_serial_reader.py    # 核心库（供 import）
├── tactile_serial_view.py      # 串口 + 2D/3D 可视化入口

├── curved_decouple_simple.py   # 弯曲解耦标定
├── realtime_decouple.py        # 实时弯曲解耦
├── realtime_slip.py            # 实时滑移检测
├── realtime_decouple_slip.py   # 解耦 + 滑移
├── slip_detection_simple.py    # 滑移库（简单）

```

## 4. 68 路传感器顺序

| 索引 | 名称 | 数量 |
|------|------|------|
| 0–3 | 拇指 A0–A3 | 4 |
| 4–7 | 食指 B0–B3 | 4 |
| 8–11 | 中指 C0–C3 | 4 |
| 12–15 | 无名指 D0–D3 | 4 |
| 16–19 | 小指 E0–E3 | 4 |
| 20–67 | 掌心 F0–F47（6×8，行优先） | 48 |

## 5. 串口与可视化（`tactile_serial_view.py`）

### 5.1 终端打印

```powershell
python tactile_serial_view.py --port COM5 --baudrate 921600
```

| 参数 | 说明 |
|------|------|
| `--port` | 串口，默认 `COM5` |
| `--baudrate` | 默认 921600 |
| `--refresh` | 单行刷新 |
| `--interval` | 刷新间隔（秒），默认 0.5 |
| `--no-calib` | 输出原始 AD |
| `--debug` | 调试输出 |

### 5.2 2D 热力图

```powershell
python tactile_serial_view.py --viz --port COM5
```

- 显示 **ΔAD**（减静止基线），色标 **0–200**
- 启动后前 **10 帧**保持静止以标基线

### 5.3 MANO 3D 热力图

```powershell
# 实时（需串口 + MANO 已配置）
python tactile_serial_view.py --viz-3d --port COM5

# 静态演示（无需手套）
python tactile_serial_view.py --viz-3d-demo
```

3D 说明：

- 左手实时数据 + 右手镜像布局
- 六区热力（拇/食/中/无名/小指/掌）**互不影响**
- 锚点缓存：`assets/mano_sensor_anchors_left.npy`（版本见 `.version` 文件）

## 6. 弯曲解耦（`curved_decouple_simple.py`）

标定空手弯曲伪触觉，抓握时以**残差**反映真实接触。

```powershell
# 1. 采集：空手慢握拳扫掠（默认约 12 s）
python curved_decouple_simple.py record --port COM5 --out bend_sweep.npz

# 可选：有 SOLVED 关节角时用 14 维关节作姿态
python curved_decouple_simple.py record --port COM5 --pose-mode joint --out joint_sweep.npz

# 2. 建库
python curved_decouple_simple.py build --sweep bend_sweep.npz --out bend_decouple_calib.npz

# 3. 回放验证（解耦前/后对比）
python curved_decouple_simple.py viz --calib bend_decouple_calib.npz --sweep bend_sweep.npz
```

| build 参数 | 说明 |
|------------|------|
| `--method nn` | 最近邻单帧（推荐） |
| `--method knn` | 高斯加权 |
| `--max-templates 0` | 使用扫掠全部帧 |

### 实时解耦

```powershell
python realtime_decouple.py --port COM5 --calib bend_decouple_calib.npz --viz
```

## 7. 滑移检测

### 7.1 原始压强

```powershell
python realtime_slip.py --port COM5 --viz --mode advance
```

| 参数 | 说明 |
|------|------|
| `--mode` | `simple` 或 `advance`（默认） |
| `--viz` | 同步 2D 热力 |
| `--sample-rate` | 初始采样率 (Hz) |
| `--calibrate-frames` | 估计采样率用帧数 |

### 7.2 解耦 + 滑移

```powershell
python realtime_decouple_slip.py --port COM5 --calib bend_decouple_calib.npz --viz --mode advance
```

需先完成第 6 节 `record` + `build`；滑移输入为**解耦后残差**。

## 10. 常见问题

**Q：`ModuleNotFoundError: tactile_serial_reader`**  
A：请在 `tactile/` 目录下运行，或确保该目录在 Python 路径中。

**Q：3D 提示找不到 MANO**  
A：确认 `mano_v1_2/models/MANO_LEFT.pkl` 存在，并运行 `python scripts/export_mano_meshes.py`。

**Q：`未找到传感点坐标`**  
A：运行 `python scripts/extract_sensor_layout_coords.py`，并确保 `assets/sensor_layout.png` 存在。

**Q：一直显示 “Calibrating baseline”**  
A：启动后 **10 帧内**保持手静止。

**Q：PowerShell 不支持 `&&`**  
A：命令分行执行，或用 `;` 连接。

## 11. 协议速查

- **帧格式**：`TOUCH seq=<n> thumb=... index=... middle=... ring=... little=... palm=<48 个 AD>`
- **压强标定**：ExpDec1，`y = A1·exp(-x/t1) + y0`（见 `tactile_serial_reader.PressureCalibration`）
- **可视化基线**：前 10 帧中位数；显示 `max(AD - baseline, 0)`

协议或布局变更请修改 `tactile_serial_reader.py`；可视化 CLI 见 `tactile_serial_view.py`。
